  # Hybrid Selenium Automation Framework

## Overview

This project is a Hybrid Data-Driven Selenium Automation Framework developed using:

- Java
- Selenium WebDriver
- TestNG
- Maven
- Apache POI
- Extent Reports
- Page Object Model (POM)

The framework supports:

✅ Data Driven Testing

✅ Cross Browser Execution

✅ Extent Reporting

✅ Screenshot Capture on Failure

✅ TestNG DataProvider

✅ DriverFactory Pattern

✅ Page Object Model

✅ Reusable Utilities
